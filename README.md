# Медкорпус Конохи · 木ノ葉医療班

Статический сайт-справочник о медицине мира Наруто с аккаунтами, составом корпуса и панелью разработчика. Сделан на чистом HTML, CSS и JavaScript — без сборки, зависимостей и фреймворков.

**Живой сайт:** https://rociseaborn228.github.io/MedCorpus/

## Аккаунты и панель разработчика

- Вход и регистрация — на странице `login.html`.
- Личный кабинет — `account.html`: профиль, должности, ранг, клан, статус, выговоры и личные рапорта.
- Панель разработчика — `admin.html`: создание, редактирование и удаление пользователей, должности, ранги, кланы, статусы, фото, устные (3) и письменные (2) выговоры, модерация рапортов.
- Раздел «Состав» на главной объединяет руководство и основной состав. Разработчик может открыть карточку участника и сразу изменить данные или выговоры, а также удалить аккаунт.
- Должность «Глава Медицинского Корпуса» автоматически показывает участника в блоке «Руководство». Если снять должность, он возвращается в основной состав.

### Важно: данные хранятся в браузере

GitHub Pages — это статический хостинг без сервера и базы данных. Поэтому:

- аккаунты, сессия, состав и рапорта хранятся в `localStorage` **конкретного браузера**;
- регистрация и изменения не видны другим посетителям;
- после очистки данных браузера локальные аккаунты и правки пропадут;
- общая база для всех посетителей потребует backend: Supabase, Firebase, PocketBase или собственный сервер.

## Как опубликовать на GitHub Pages

### Через браузер

1. Создайте публичный репозиторий `MedCorpus`.
2. Загрузите все файлы проекта, включая папки `css`, `js`, `images` и файл `.nojekyll`.
3. Откройте **Settings → Pages**.
4. **Source**: `Deploy from a branch`; **Branch**: `main`, папка `/ (root)`; **Save**.
5. Через 1–3 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/MedCorpus/`.

### Через GitHub CLI без установленного Git

```powershell
gh repo create MedCorpus --public
gh api --method PUT "repos/ВАШ-ЛОГИН/MedCorpus/contents/index.html" -f message="Upload" -f content="$(base64 index.html)"
```

Для массовой загрузки удобнее использовать GitHub Contents API или установить Git. В этом проекте сайт уже опубликован в `RociSeaBorn228/MedCorpus`.

## Как обновлять сайт

- Через браузер: откройте файл в репозитории → карандаш **Edit** → **Commit changes**.
- Через Git: измените файлы, затем `git add . && git commit -m "правки" && git push`.
- GitHub Pages пересобирается автоматически за ~1 минуту. Обновляйте страницу с `Ctrl + F5`.

## Оформление

- Тёмная тема: фон `#0d0d0d`, карточки `#151515`, акцент `#388e3c`.
- Цвета, шрифты и отступы — в начале `css/style.css`, блоки `:root` и `[data-theme="light"]`.
- Главный акцент — переменная `--accent`.
- Светлая/тёмная тема переключается кнопкой в шапке, выбор запоминается в браузере.
- Тексты страниц лежат прямо в HTML — ищите нужный абзац по словам.

## Важные мелочи

- Все ссылки относительные, поэтому сайт работает и в подпапке GitHub Pages.
- Не переименовывайте `index.html` — это точка входа.
- GitHub различает регистр букв: `Images/Logo.svg` и `images/logo.svg` — разные пути.
- Файл `.nojekyll` отключает обработку Jekyll.
- `404.html` GitHub Pages показывает автоматически при переходе на несуществующий адрес.
- Фото участников: прямая ссылка на картинку (`https?://…/photo.jpg`) или ссылка на пост/галерею Imgur (например, `https://imgur.com/gallery/...`). Ссылки Imgur при сохранении превращаются в прямую ссылку на изображение; неподходящие адреса отклоняются с понятной ошибкой. Пользовательский текст экранируется.
