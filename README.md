## Как опубликовать на GitHub Pages

### Вариант 1 — через браузер (без установки программ)

1. Зарегистрируйтесь на [github.com](https://github.com) и создайте репозиторий: **New repository**.
2. Название — например `MedCorpus`. Видимость — **Public**.
3. Нажмите **Add file → Upload files** и перетащите в окно **всё содержимое этой папки**:
   - все `.html`-файлы;
   - папки `css`, `js`, `images`;
   - файл `.nojekyll` (в проводнике Windows включите показ скрытых файлов) и `README.md`.
4. Нажмите **Commit changes**.
5. В репозитории откройте **Settings → Pages**.
6. В блоке **Build and deployment**:
   - **Source**: `Deploy from a branch`;
   - **Branch**: `main`, папка `/ (root)`;
   - **Save**.
7. Подождите 1–3 минуты и обновите страницу. Ссылка появится сверху:
   `https://ВАШ-ЛОГИН.github.io/MedCorpus/`

Сайт откроется у любого человека без входа в GitHub.

### Вариант 2 — через Git

```bash
git init
git add .
git commit -m "Медкорпус Конохи: первый релиз"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/MedCorpus.git
git push -u origin main
```

Затем включите Pages в **Settings → Pages** так же, как в варианте 1.

> Если назвать репозиторий `ВАШ-ЛОГИН.github.io`, сайт откроется по короткому адресу `https://ВАШ-ЛОГИН.github.io/` — без имени репозитория в конце.

## Как обновлять сайт

- Через браузер: откройте файл в репозитории → карандаш **Edit** → внесите правки → **Commit changes**.
- Через Git: измените файлы, затем `git add . && git commit -m "правки" && git push`.
- GitHub Pages пересобирается автоматически за ~1 минуту. Обновляйте страницу с `Ctrl + F5`.

## Как менять оформление

- Цвета, шрифты и отступы — в начале `css/style.css`, блок `:root` (тёмная тема) и `[data-theme="light"]` (светлая).
- Главный акцент — переменная `--accent`.
- Светлая/тёмная тема переключается кнопкой в шапке, выбор запоминается в браузере.
- Тексты страниц лежат прямо в HTML — ищите нужный абзац по словам.

## Важные мелочи

- Все ссылки относительные (`css/style.css`, `tehniki.html`), поэтому сайт работает и в подпапке GitHub Pages.
- Не переименовывайте `index.html` — это точка входа сайта.
- GitHub различает регистр букв: `Images/Logo.svg` и `images/logo.svg` — разные пути.
- Файл `.nojekyll` отключает обработку Jekyll. Он не обязателен для этого сайта, но полезен, если вы добавите папки с подчёркиванием в начале имени.
- `404.html` GitHub Pages показывает автоматически при переходе на несуществующий адрес внутри сайта.
